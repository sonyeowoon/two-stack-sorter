# Two Stack Sorter

두 스택과 제한된 이동·교환·회전 연산을 사용해 정수를 정렬하는 C 알고리즘 학습 프로젝트입니다. 정렬을 수행하는 연산 명령을 표준 출력으로 내보냅니다.

## 주요 구현

- 연결 리스트 기반 스택 구성과 입력 검사
- 피벗을 이용한 값 분할 및 보조 스택 이동
- 작은 크기의 스택에 대한 정렬 처리
- 원래 스택으로 되돌릴 대상 선택과 회전 처리
- 최솟값을 스택 상단에 배치하는 마무리 처리

## 기술

C, 연결 리스트, 스택, 피벗 분할, 동적 메모리 관리, Make

## 빌드와 실행

C 컴파일러와 Make가 필요합니다. 저장소 루트에서 실행합니다.

```sh
make
./push_swap 3 2 1
```

실행 파일 이름은 기존 Makefile의 `push_swap`을 유지합니다. 출력은 정렬된 숫자 목록이 아닌 스택 연산 명령입니다.

## 코드 안내

| 파일 | 내용 |
| --- | --- |
| `ft_sorting.c` | 분할·정렬·복귀의 전체 흐름 |
| `find_median.c` | 피벗 계산 관련 처리 |
| `make_stack.c` | 입력으로 스택 구성 |
| `push_swap_cmd.c`, `stack_control.c` | 스택 연산 |
| `pa_all_utils.c`, `pa_all_utils2.c` | 복귀 대상 선택 관련 처리 |

## 범위

제약된 연산 집합으로 정렬 과정을 구현하는 학습용 프로그램입니다. 모든 입력에 대한 최소 연산 수를 보장하지 않습니다. 입력 크기별 연산 수와 메모리 검사는 별도 측정이 필요하며, 이 문서에서는 측정하지 않은 성능 수치를 제시하지 않습니다.
